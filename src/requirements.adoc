= Спецификация требований
:version: 1.0

== Бизнес-требования (BR)

[cols="1,3", options="header"]
|===
| ID | Формулировка
| [[BR-01]]BR-01 | Сократить время получения генеральным директором актуального состояния продаж интернет-магазина, чтобы управленческие решения принимались по свежим данным, а не по отчетности, устаревшей к моменту получения.
| [[BR-02]]BR-02 | Сократить долю рабочего времени старшего аналитика, затрачиваемого на ручной сбор и сведение данных в Excel, чтобы высвободить время для анализа продаж и подготовки отчётности, включая отчётность для инвесторов.
| [[BR-03]]BR-03 | Обеспечить руководителя отдела продаж оперативными данными (Количество проданных товаров, топ - 3 самых популярных товаров, выполнение плана), чтобы планы по увеличению продаж строились на актуальной картине, а не на устаревших данных.
|===

== Функциональные требования (FR)

[cols="1,3", options="header"]
|===
| ID | Формулировка
| [[FR-01]]FR-01 | Подсистема формирования отчетности продаж должна считать показатель актуальным только при наличии времени последнего успешного обновления, полученного из существующей базы интернет-магазина, и не отображать показатель как актуальный, если обновление не выполнялось.
| [[FR-02]]FR-02 | Подсистема должна предоставлять пользователю выбор периода и отображать ключевые показатели продаж (выручку, количество проданных товаров, топ-3 товара, выполнение плана) за выбранный период.
| [[FR-03]]FR-03 | Подсистема должна определять топ-3 товара по количеству проданных единиц за месяц и отображать их пользователю в порядке убывания продаж.
| [[FR-04]]FR-04 | Если адаптер чтения базы интернет-магазина не получил данные за 10 секунд или получил ошибку чтения, показатель  переводится в статус неактуального, время последнего успешного обновления не сдвигается, а факт сбоя записывается в журнал событий.
|===

== Пользовательские требования (UR)

[cols="1<,3<", options="header"]
|===
| ID | Формулировка
| [[UR-01]]UR-01 | Генеральный директор должен за один экран видеть ключевые показатели продаж: выручку, количество проданных товаров, топ-3 товара и выполнение плана за выбранный период, с указанием времени последнего обновления, чтобы понимать, насколько данные актуальны.
| [[UR-02]]UR-02 | Старший аналитик должен видеть ключевые показатели продаж в подсистеме уже рассчитанными на основе данных базы интернет-магазина, без ручного сбора и сведения данных в Excel, чтобы использовать время на анализ, а не на сбор.
| [[UR-03]]UR-03 | Руководитель отдела продаж должен видеть количество проданных товаров, топ - 3 самых популярных товаров, выполнение плана за выбранный период, чтобы строить планы по увеличению продаж на актуальной картине.
|===

== Нефункциональные требования (NFR)

[cols="1,3", options="header"]
|===
| ID | Формулировка
| [[NFR-01]]NFR-01 | Обновление ключевых показателей продаж в подсистеме должно выполняться не реже одного раза в час, а время последнего успешного обновления должно быть доступно пользователю. Если с момента последнего успешного обновления прошло более часа, предупреждение(устарел) должно отображаться пользователю не позднее чем через 5 минут после истечения часа.
| [[NFR-02]]NFR-02 | Отклик подсистемы при открытии и смене периода должен составлять не более 3 секунд в 95 % обращений при нагрузке до 10 одновременных пользователей.
|===

== Бизнес-правила (BP)

Бизнес-правила описывают, *как именно* система должна считать показатели. Они не являются требованиями к функциям, но без них система не сможет работать корректно.

[cols="1,3", options="header"]
|===
| ID | Формулировка
| [[BP-01]]BP-01 | Выручка считается по выкупленным заказам за период за вычетом возвратов; количество проданных товаров: по проданным единицам за вычетом возвращенных; топ-3 товара: по количеству проданных единиц за месяц; выполнение плана: как отношение фактической выручки к плану, заданному на месяц по всему магазину.
| [[BP-02]]BP-02 | Если данных за период нет, показывается последнее значение с пометкой и временем обновления. Правило действует и без автоматизации: так в организации считается отчетность.
|===
