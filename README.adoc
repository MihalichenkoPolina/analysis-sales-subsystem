== Назначение комплекта

Данный репозиторий содержит комплект проектной документации для аналитической подсистемы продаж интернет-магазина. 
Цель подсистемы — предоставление генеральному директору, старшему аналитику и руководителю отдела продаж актуальной отчетности без ручного сбора данных в Excel.

== Состав комплекта

* link:src/requirements.adoc[Спецификация требований (BR, UR, FR, NFR, BP, L)]
* link:src/interfaces.adoc[Описание интерфейсов и макетов (IF-01, UI-01, UI-02)]

== Порядок чтения

1. Начните с `src/requirements.adoc` — там описаны бизнес-цели и функциональные требования.
2. Затем изучите `src/interfaces.adoc` — там описано, как именно эти требования реализуются в интерфейсах.

== Правила сборки

Исходные файлы документов (`.adoc`) хранятся в папке `src/`.
Готовые документы (HTML/PDF) собираются с помощью компилятора Asciidoctor и помещаются в папку `build/`.
